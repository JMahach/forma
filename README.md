# Форма

Форма строит карту Human Design по дате, времени и городу рождения. В приложении можно исследовать карту, двигаться по времени, смотреть транзиты и возвраты и читать объяснения рисунка.

Текущая линия проекта — Форма 0.2. Браузер и сервер написаны на TypeScript, расчёты выполняет Python. Для запуска нужны Node.js 24 и Python 3.12; версии зависимостей закреплены в репозитории.

## Разработка и проверки

Запускайте команды из корня проекта после установки по инструкции эксплуатации:

```sh
npm run typecheck
npm run check:architecture
npm run build
```

Для изменения конкретного владельца сначала достаточно соответствующего поведенческого теста, например `node --test tests/library-fill-owner.test.ts`. Полные команды — `npm test` и `npm run test:python`; они нужны для общей проверки, а не после каждой небольшой правки. `npm run typecheck:tests` отдельно проверяет типы тестовых фикстур; известный долг на завершении рефакторинга отмечен в истории.

Главный контроль изменения: сколько запросов, расчётов и реальных записей вызывает действие до и после. Новое управление подключается сразу, прежнее удаляется. Готовые пригодные данные не получают повторного запроса только из-за наличия интернета.

Для изменений порядка действий начните с таблицы правил в архитектуре. Для изменений данных — с договора в `shared/` и владельца хранения. Представления и окна остаются в `views/` и `ui/`.
