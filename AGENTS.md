# Правила работы над Формой

## GitHub Actions запрещены

По прямому требованию автора не создавать и не восстанавливать GitHub Actions workflows в этом проекте. Проверки запускать вручную перед публикацией.

## Заповедь структуратора: кэш только по согласованию

**Ни один новый кэш не появляется без предварительного явного согласования с автором проекта.** Это касается браузера и сервера, памяти и постоянного хранения, HTTP-кэша и скрытой мемоизации результатов.

До реализации объясни простыми словами:

- что именно будет сохраняться и какую повторную работу это убирает;
- почему существующего хранения недостаточно;
- какой модуль владеет данными;
- где они лежат, сколько занимают, когда устаревают и как вытесняются;
- что происходит при промахе, отказе записи и смене версии расчёта.

Дождись согласования. Затем внеси кэш в соответствующую таблицу раздела README «Кэш: что и где хранится» и поддерживай описание одновременно с кодом. Кэш, отсутствующий в этом разделе, не считается завершённой частью реализации.

Изменение состава сохраняемых данных, места хранения, лимитов или правил очистки существующего кэша тоже согласовывается заранее. Нельзя обойти правило, назвав кэш буфером, запасом или вспомогательной Map.

Уже полученное согласование действует для реализации принятого решения. Исправление ошибки в рамках согласованной политики не требует повторного разрешения. Текущее состояние интерфейса и незавершённый запрос сами по себе не являются кэшем результатов.
