# Форма

«Форма» превращает дату, время и город рождения в интерактивную схему Human Design. Можно рассматривать связи, приближать рисунок, выбирать ворота и исследовать каждую минуту дня. Расчёт и справочник городов работают локально; публичный сервер для запуска не нужен.

Этот README — карта проекта: **что считается, где это лежит и как части связаны**.

## Как всё связано

| Часть | Простыми словами | Работа |
| --- | --- | --- |
| Браузер | Альбом и пульт | Показывает карту, хранит библиотеку, обрабатывает выбор, жесты и минуту дня |
| Node | Приёмная | Принимает запросы, находит город, управляет очередями и отдаёт результат |
| Python | Калькулятор | Переводит местное время в UTC и рассчитывает положения на небесном круге |

```text
Дата + время + город → форма → API Node → Python / Swiss Ephemeris
                                 ↑                 │
                                 └── готовая карта ┘
                                           │
                           библиотека → выбранная карта → SVG
                                                            ↑
Ползунок → готовый пакет дня → временная минута ──────────────┤
Клик / Shift → выбранные элементы → подсветка ────────────────┤
Перетаскивание / pinch → камера → масштаб и положение ────────┘
```

Перетаскивание рисунка не запускает Python. Нажатие на ворота меняет выделение. Ползунок уже загруженного дня выбирает готовую минуту. Серверный расчёт нужен для новой карты или отсутствующего пакета дня.

**Три вопроса о масштабе — три обязанности.** Геометрия говорит, какой формы рисунок. Layout решает, как вписать его вместе с колонками и шкалой в окно. Камера хранит, насколько пользователь приблизил и сдвинул его. Поэтому не нужно искать все похожие числа в одном огромном файле: сначала определите, какое правило меняется.

## Где какая математика

| Что считаем | Простое объяснение | Файл |
| --- | --- | --- |
| Местное время → UTC | Учитываем исторический пояс города, повторившееся или несуществующее время | [civil_time.py](server/python/civil_time.py) |
| Положения на круге | Swiss Ephemeris возвращает 11 исходных долгот. Земля задаётся напротив Солнца, Южный узел — напротив Северного: получается 13 активаций одной стороны | [astronomy.py](server/python/astronomy.py) |
| Момент Дизайна | Ищем более ранний момент, когда Солнце отстаёт на 88°. Это угол, а не 88 суток | [astronomy.py](server/python/astronomy.py) |
| Ворота и линия | Круг делится на 64 сектора по 5,625°, сектор — на 6 линий по 0,9375°. Номера ворот берутся из таблицы | [gate-wheel.js](src/domain/gate-wheel.js); серверное соответствие — `astronomy.py` |
| Цвет, тон, база | Линия делится на 6 цветов, цвет — на 6 тонов, тон — на 5 баз | [substructure.js](src/domain/substructure.js) |
| Четыре пары стрелок | По цветам и тонам согласованных активаций определяем направления | [variables.js](src/domain/variables.js) |
| Полные каналы и центры | Оба конца канала активны → канал полный → связанные центры определены | [topology.js](src/domain/topology.js) |
| Сводка и профиль | Считаем сохранённые активации, читаем линии Солнца обеих сторон | [chart-facts.js](src/domain/chart-facts.js) |
| Фиксация линии | Сопоставляем активации с таблицей правил | [line-fixing.js](src/domain/line-fixing.js), [line-fixing-data.js](src/domain/line-fixing-data.js) |
| Крест мандалы | Готовая долгота → четыре точки и ворота креста; указатель сначала переводится в угол | [mandala-cross.js](src/domain/mandala-cross.js), [mandala-preview.js](src/scene/mandala-preview.js) |
| Минута дня → карта | Читаем уже рассчитанные долготы из пакета, восстанавливаем активации | [transit-day.js](src/domain/transit-day.js), [natal-day.js](src/domain/natal-day.js), [day-timeline.js](src/domain/day-timeline.js) |

У рождения две стороны: Личность в момент рождения и Дизайн в найденный более ранний момент. У транзита один набор без натального Дизайна. Процент внутри ворот, линии или подразделения означает **положение на отрезке**, а не выраженность качества человека. Округлённая подпись не участвует в расчёте.

## Кто хранит состояние

| Что | Владелец |
| --- | --- |
| Сохранённая коллекция | [chart-store.js](src/data/chart-store.js); запись в браузер — [storage.js](src/data/storage.js) |
| Выбранная запись и источник показанной карты | [chart-session.js](src/state/chart-session.js): берёт оригинал из коллекции или временную карту из контроллера дня |
| Минута транзита и режим «Сейчас» | [state/live-transit.js](src/state/live-transit.js) отдельно отслеживает готовность текущей карты и всей шкалы дня |
| Исходная карта рождения и временная минута | [state/natal-day.js](src/state/natal-day.js) |
| Закреплённый выбор, группы сводки и кресты | [selection-model.js](src/selection/selection-model.js) хранит общую модель; [summary-selection-state.js](src/selection/summary-selection-state.js) — правила групп сводки; [selection-state.js](src/selection/selection-state.js) — обычный выбор |
| Временное наведение | [hover-preview.js](src/selection/hover-preview.js) |
| Масштаб и положение | [camera.js](src/scene/camera.js); события — [gestures.js](src/scene/gestures.js) |
| Режим и переход мандалы, вариант подложки | [mandala.js](src/scene/modes/mandala.js), [mandala-motion.js](src/scene/modes/mandala-motion.js), [lotus.js](src/scene/modes/lotus.js) |

**Каждое пришедшее событие `input` шкалы обрабатывается по порядку.** Ускорение уменьшает стоимость обновления, сохраняя промежуточное движение активаций. Здесь нет отбрасывания минут до последнего значения кадра. Наведение мандалы и камера обновляют изображение перед кадром. При этом каждое движение камеры сразу меняет её численное состояние; окончание жеста и программные команды применяются сразу. Правило обработки минут шкалы сохраняется.

Временный просмотр минуты не перезаписывает сохранённую карту.

## Запуск на Mac / Linux

Для новой копии нужны Node.js 24 и Python с зависимостями из `requirements.txt`:

```sh
git clone https://github.com/JMahach/forma.git
cd forma
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm start
```

Репозиторий может требовать доступ GitHub. Для подготовленной копии достаточно `npm start`. Откройте [127.0.0.1:4173](http://127.0.0.1:4173); остановка — `Ctrl+C`. Обычный запуск читает исходные модули и не требует сборки. Python-зависимости закреплены в [requirements.txt](requirements.txt): `pyswisseph==2.10.3.2`, `tzdata==2026.3`.

Компактная сборка — отдельный режим: `npm ci` устанавливает закреплённый сборщик, `npm run build` создаёт `dist/`, `npm run start:release` запускает этот вариант локально. Эти команды не публикуют сайт. После изменения исходников компактную сборку нужно создать заново и перезапустить сервер.

Нужны `data/cities.json`, `data/ephe/sepl_18.se1`, `data/ephe/semo_18.se1`; они входят в подготовленный проект. Первая установка загружает Python-пакеты, последующие расчёты и поиск городов работают без внешних запросов. `.venv` создают заново на каждом компьютере; при отсутствии готового пакета `pyswisseph` могут понадобиться инструменты компиляции.

| Настройка | По умолчанию | Зачем |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | Интерфейс Node |
| `PORT` | `4173` | Другой порт: `PORT=4174 npm start` |
| `TRANSIT_CACHE_DIR` | `.cache/transit/v1` внутри проекта | Дисковый кэш общего транзита |

После правки JS/CSS обновите страницу. После изменения сервера или списка публичных файлов перезапустите `npm start`. Браузерные модули разрешаются в [server/http/public-files.mjs](server/http/public-files.mjs).

Для телефона в той же доверенной Wi-Fi-сети запустите `HOST=0.0.0.0 npm start` и откройте `http://<локальный-IP-компьютера>:4173`. Компьютер должен оставаться включённым. Это доступ для локальной сети; авторизации и HTTPS в самом Node нет.
